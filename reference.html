Guidelines

Accessibility Notes

info Contrast check needed: Body text (#6B7280) on white has a 4.6:1 ratio — passes AA but just barely. On #FAFAFA backgrounds it drops to ~4.4:1. Consider darkening body text to #4B5563 for safer margins.
check_circle Primary buttons pass: White text on #171796 has excellent contrast (12.5:1).
warning Muted text (#9CA3AF) on white is 2.9:1 — fails WCAG AA for normal text. Acceptable for decorative/non-essential content only. Consider #6B7280 for any functional captions.
info Focus states: All interactive elements include visible focus rings using the primary blue. Test with keyboard navigation before launch.

Developer Reference

New Architecture

// File structure
tailwind.config.js        // Single source of truth for all tokens
assets/css/main.css       // @tailwind directives + minimal @layer components
components/
  atoms/
    Button.php              // $variant, $size, $icon, $disabled
    Badge.php               // $variant, $label
    Icon.php                // $name, $size
    Input.php               // $name, $label, $error, $hint
    Select.php              // $name, $label, $options
    Textarea.php            // $name, $label, $hint
    Checkbox.php            // $name, $label, $type (checkbox|radio)
    Link.php                // $label, $href, $external
  molecules/
    Alert.php               // $type, $message (auto icon)
    Card.php                // $content, $href
    FormField.php           // Delegates to atoms based on $type
  organisms/              // Coming soon
docs/
  MIGRATION.md              // Full migration guide
  legacy-tokens/          // Archived v1 CSS files

PHP Component Usage

// Button
<?php
$variant = 'primary';
$size    = 'md';
$label   = 'Get Started';
$icon    = 'arrow_forward';
include 'components/atoms/Button.php';
?>

// Alert
<?php
$type    = 'success';
$message = '<strong>Done!</strong> Your tour is booked.';
include 'components/molecules/Alert.php';
?>

// Input with error
<?php
$name  = 'email';
$label = 'Email Address';
$type  = 'email';
$error = 'Please enter a valid email.';
include 'components/atoms/Input.php';
?>
