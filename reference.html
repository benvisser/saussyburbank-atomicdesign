Guidelines

Accessibility Notes

info Contrast check needed: Body text (#6B7280) on white has a 4.6:1 ratio — passes AA but just barely. On #FAFAFA backgrounds it drops to ~4.4:1. Consider darkening body text to #4B5563 for safer margins.
check_circle Primary buttons pass: White text on #171796 has excellent contrast (12.5:1).
warning Muted text (#9CA3AF) on white is 2.9:1 — fails WCAG AA for normal text. Acceptable for decorative/non-essential content only. Consider #6B7280 for any functional captions.
info Focus states: All interactive elements include visible focus rings using the primary blue. Test with keyboard navigation before launch.

Developer Reference

Tailwind Configuration

Copy this into your tailwind.config.js → theme.extend to use these tokens as utility classes.

// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      colors: {
        primary:       { DEFAULT: '#171796', hover: '#0D0D61', light: '#EFEFEF' },
        secondary:     { DEFAULT: '#EFEFEF', hover: '#E3E3E3' },
        dark:          '#35373C',
        body:          '#6B7280',
        muted:         '#9CA3AF',
        border:        '#E5E7EB',
        surface:       { DEFAULT: '#FFFFFF', alt: '#FAFAFA', dark: '#35373C' },
        success:       { DEFAULT: '#10B981', light: '#34C092' },
        warning:       { DEFAULT: '#D97706', light: '#F59E0B' },
        error:         { DEFAULT: '#EF4444', light: '#FEF2F2' },
        info:          { DEFAULT: '#2563EB', light: '#EFF6FF' },
      },
      fontFamily: {
        display: ['larken', 'Georgia', 'serif'],
        body:    ['proxima-nova', 'Helvetica Neue', 'Arial', 'sans-serif'],
      },
      borderRadius: {
        full: '9999px',
      },
      maxWidth: {
        site: '1280px',
        content: '960px',
      },
    },
  },
}
