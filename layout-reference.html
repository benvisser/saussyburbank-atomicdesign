Key Design Decisions

Typography shift
The original uses bold sans-serif headings. The SB version switches to Larken (thin weight) for a refined, editorial feel that matches the brand's luxury positioning.
Eyebrow as brand accent
The original's text-indigo-600 eyebrow becomes the H4 subheading pattern in text-primary (#171796). On a white surface, the brand primary works perfectly as the accent color.
Icon system
Heroicons SVGs are replaced with Material Symbols Outlined (filled variant). This keeps icon usage consistent and eliminates inline SVG markup. Use icon-sm (18px), icon-md (24px), or icon-lg (32px).
Text hierarchy
Tailwind UI uses gray-900 / gray-700 / gray-600 for 3-tier hierarchy. The design system simplifies to text-dark (#35373C) for headings and text-body (#6B7280) for descriptions — cleaner and more consistent.

Images <img> (Tailwind Plus assets) Placeholder / project images Replace with actual screenshots or photography

Key Design Decisions

Three-layer card structure
Each card uses a bg layer (white fill), inner layer (clips overflow for images), and overlay layer (shadow + border). This allows images to be clipped to rounded corners while the border renders cleanly above.
Bento corner rounding
The outer grid edges use 24px radius for the signature bento look, while inner card edges use the standard rounded-lg (12px). On mobile, the top and bottom cards get extra rounding instead of left/right.
Alt surface background
Unlike other sections that use bg-surface (white), the bento uses bg-surface-alt (#FAFAFA) so the white cards have visible contrast against the background.
Image placeholders
The original uses Tailwind Plus screenshot assets. In production, replace placeholders with actual product photography, UI screenshots, or illustrations that match the card's content.
