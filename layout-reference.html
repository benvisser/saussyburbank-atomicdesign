Key Design Decisions

Typography shift
The original uses bold sans-serif headings. The SB version switches to Larken (thin weight) for a refined, editorial feel that matches the brand's luxury positioning.
Eyebrow as brand accent
The original's text-indigo-600 eyebrow becomes the H4 subheading pattern in text-primary (#171796). On a white surface, the brand primary works perfectly as the accent color.
Icon system
Heroicons SVGs are replaced with Material Symbols Outlined (filled variant). This keeps icon usage consistent and eliminates inline SVG markup. Use icon-sm (18px), icon-md (24px), or icon-lg (32px).
Text hierarchy
Tailwind UI uses gray-900 / gray-700 / gray-600 for 3-tier hierarchy. The design system simplifies to text-dark (#35373C) for headings and text-body (#6B7280) for descriptions — cleaner and more consistent.

Key Design Decisions

Three-layer card structure
Each card uses a bg layer (white fill), inner layer (clips overflow for images), and overlay layer (shadow + border). This allows images to be clipped to rounded corners while the border renders cleanly above.
Bento corner rounding
The outer grid edges use 24px radius for the signature bento look, while inner card edges use the standard rounded-lg (12px). On mobile, the top and bottom cards get extra rounding instead of left/right.
Alt surface background
Unlike other sections that use bg-surface (white), the bento uses bg-surface-alt (#FAFAFA) so the white cards have visible contrast against the background.
Image placeholders
The original uses Tailwind Plus screenshot assets. In production, replace placeholders with actual product photography, UI screenshots, or illustrations that match the card's content.

Card Image — Component Anatomy

.card-image
Root element (<a> or <div>). Sets aspect-ratio: 3/4, overflow: hidden, and rounded-lg (12px). Acts as the positioning context for all child layers.
.card-image__img
Full-bleed image with object-fit: cover. Scales to 1.05x on hover for a subtle zoom. Replace with .card-image__placeholder when no photo is available.
.card-image__overlay
Bottom-to-top gradient from rgba(0,0,0,0.55) to transparent. Ensures white label text is always readable regardless of image content. Darkens slightly on hover.
.card-image__label
Location name in Larken italic, thin weight. Positioned bottom-left with space-6 (24px) padding. Responsive: 24px mobile → 30px on sm+.

Key Design Decisions

Dark surface context
This is the first layout using bg-surface-dark (#35373C). Heading text uses text-surface-dark-text (#F9FAFB). The dark background creates dramatic contrast with the home photography and the white card labels.
Left-aligned heading
Unlike other section layouts which center the heading, this pattern left-aligns it with a max-width of ~480px. This creates visual asymmetry with the blueprint illustration on the right, matching the reference design.
Italic display labels
Card labels use Larken in italic to evoke an editorial, magazine-quality feel. The thin weight (100) and italic combination creates an elegant, luxurious look appropriate for a homebuilder brand.
Blueprint decoration
The faint house outline uses Material Symbols with FILL: 0 and wght: 100 to create a thin line-drawing effect. In production, replace with an actual architectural SVG illustration for a more polished result.

Key Design Decisions

Accent colors on dark surface
The original uses text-indigo-400 (a lighter indigo) for accents on the dark card. Since our primary (#171796) has poor contrast on bg-surface-dark, we use text-surface-dark-text (#F9FAFB) and white for all accent elements on the featured card.
Price as display type
The original uses bold sans-serif for prices. The SB version uses Larken thin weight, turning the price into an elegant display element that matches the heading hierarchy — dramatic yet refined.
Card nesting behavior
On tablet (sm), the light card loses bottom rounding and gains horizontal margin to tuck behind the featured card. On desktop (lg), it instead loses the right-side rounding to sit flush against the featured card. This creates a visual "upgrade path" leading the eye right.
Homebuilder adaptation
Pricing is reframed as "starting from $XXXs" instead of exact monthly costs. The feature list becomes home specs (bedrooms, sq ft, finishes) rather than software features. CTAs use "Explore Floor Plans" to drive engagement.
